# App FIX - Precificação de Rótulos e Etiquetas

## Como testar no computador
1. Instale Python 3.11 ou superior.
2. Abra o Prompt de Comando dentro desta pasta.
3. Rode:
   pip install -r requirements.txt
4. Depois:
   streamlit run app.py

## Como publicar grátis no Streamlit Community Cloud
1. Crie uma conta no GitHub.
2. Crie um repositório novo.
3. Envie os arquivos:
   - app.py
   - requirements.txt
   - logo_fix.png
4. Entre no Streamlit Community Cloud.
5. Clique em "Create app".
6. Conecte o repositório do GitHub.
7. Selecione app.py.
8. Publique.
